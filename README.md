# Mohammed Anas P — Portfolio

Static portfolio site. No build step.

## Deploy on GitHub Pages
1. Push the contents of this folder to a repo (e.g. `Anasanu777.github.io`).
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://<username>.github.io/`.

## Files
- `index.html` — the site
- `support.js` — runtime required by index.html (keep beside it)
- `assets/` — photo, CV page images, CV PDF

Note: open via a web server (GitHub Pages, or `python -m http.server`), not by double-clicking the file.
